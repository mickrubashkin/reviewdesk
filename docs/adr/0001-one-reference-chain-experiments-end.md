# One reference chain; every difference is an adaptation or an experiment

A board has one reference chain. Regions adapt it where the region differs (currency, contract links, timing). Anything else that differs is an experiment: it has its own source emails that its regions adapt, and it ends by being adopted into the reference, rolled back, or kept as part of a region's adaptation. Free-standing copies per manager or region are not allowed, because they drifted apart unseen (the old manager copies) and left no way to compare or merge them.

## Considered Options

- Separate chains per variation: freedom for managers, but no comparison and no way back.
- A frozen single chain: consistent, but blocks the experiments managers will run anyway.
