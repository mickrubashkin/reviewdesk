# Regions and the reference

Some boards serve several regions. A region differs from the others in a few things (currency, links to contracts and rules, sometimes the timing), not in the whole email. One region is the **reference**: its chain is the one the other regions adapt.

## Where to see the difference

- **Timeline:** one branch per region, the reference first, lined up slot by slot. A wait that differs from the reference is marked.
- **Matrix:** switch the columns to regions. Each cell says how the region's email stands against the reference: **same as reference**, what **differs**, or empty.
- **Review page → Details:** the reference section says which reference email this one is based on, whether the reference changed since and what to take, and how the email differs now.

## When the reference changed

An email based on the reference shows **reference changed** when the reference email changed after this one last matched it.

1. Open the email and look at **Details**: it lists what changed in the reference.
2. Take what applies to your region, keep what is meant to differ.
3. Click **Mark up to date**.

## Set the region

A region manager sets the email's region in **Details → Region**. Emails without a region show up as **No region**. The regions of a board are set in **Board settings**.
