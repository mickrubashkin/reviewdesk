# Email Review Rules

Review only email text and metadata. Ignore HTML, CSS, layout, rendering, accessibility, and template implementation.

Check:

- Subject: clear reason to open.
- Preheader: adds context, does not just repeat subject.
- Focus: one primary action, no competing asks. A support option is acceptable when it helps the user complete the primary CTA and is phrased as help, not as an alternative next step.
- CTA: specific, visible in copy, aligned with stage goal.
- Timing: tone fits immediate, follow-up, or last-call timing.
- Language: matches declared language, no accidental mixed-language fragments.
- Readability: concise, scannable, easy to act on.
- Onboarding fit: moves the account toward activation, first value, or expansion.

Return practical recommendations a marketer or partner manager can apply directly.
