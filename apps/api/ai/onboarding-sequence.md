# Onboarding Sequence

Goal: move new accounts from signup to a habit of regular use and a paid plan.

Core principles:

- One email = one action.
- Reduce friction before pressure.
- Increase urgency in follow-ups.
- Keep copy short and outcome-focused.
- Activation happens when the account completes setup and reaches its first result.

Stage guide:

| Stage | Goal | Expected CTA | Review focus |
| --- | --- | --- | --- |
| signup | Confirm the account and set expectations | Verify email / finish signup | Welcome, low pressure |
| profile | Collect the details that personalize the product | Complete profile | Explain why the details matter |
| activation | Finish setup | Complete setup | Make the setup step the single clear action |
| education | Teach the core workflow | Start the guided tour / watch the walkthrough | Link learning to a concrete result |
| integration | Connect the tools the account already uses | Connect an integration | Show the value of connecting, address effort |
| first-value | Reach the first meaningful result | Create the first project / send the first report | Move from setup to real use |
| expansion | Grow usage across the team | Invite teammates / upgrade plan | Tie the ask to value already received |
| retention | Bring back inactive accounts | Return to the product / book a check-in | Be specific about what changed or is waiting |

Timing intent:

- Next step / immediately: clear next action, low pressure.
- Follow-up 1: reminder; reduce friction.
- Follow-up 2: stronger value or urgency.
- Last call: clear consequence, deadline, or final chance.
